## How this maps to a PM day (robinhoodhood)
- Demand a written thesis (drivers, risks, invalidation) before treating a name as investable research.
- Prefer process metrics (alpha measurement, risk, portfolio construction) over narrative alone.
- Use student-fund / practicum patterns as the model for paper-book discipline: log, review, reflect.
- Alternatives / HF electives → treat leverage, liquidity, and short exposure as explicit risk objects, never implied.
