# Memo 04 — Track record and credibility

**Source:** [HedgeThink](https://www.hedgethink.com/how-to-become-a-hedge-fund-manager/) (*Building Credibility and Investor Confidence*, *Securing Essential Capital*).  
**Framing:** Dry-run paper book = the “prototype fund” used to build a documented track record before any live capital narrative.

## Prototype-fund discipline

1. **Log everything:** `record_outcome`, research events, reflections — every material decision.
2. **Separate paper vs live:** Never blur dry-run marks with live fills.
3. **Readiness gate:** Only discuss live unlock after `check_live_readiness` passes on real dry-run history **and** human sets MODE=live.
4. **Fee / return honesty:** No fabricated IRR or fee schedules in agent reports; if discussing a future fund, mark as hypothetical.

## Investor-style reporting (IR lite)

Each cycle / AM-PM pass should be readable by a skeptical outsider:

- What was the thesis?
- What evidence (bars, sentiment, IBD, chatter)?
- What did the model decide vs what the human approved?
- What risk controls fired?
- What is the running paper PnL and drawdown context (`get_paper_pnl_chart`)?

## Seed capital narrative (conceptual only)

HedgeThink stresses founder/friends/anchor capital. For this stack, **seed = paper equity + time-in-process**. Do not invent AUM. Credibility comes from process length, completeness of logs, and readiness metrics — not from claimed AUM.

## Agent checklist

- [ ] Outcomes recorded for closed paper trades.
- [ ] Reflection generated on schedule (especially evening IBD pass).
- [ ] No live-mode language when status is dry-run.
- [ ] Cite this memo + HedgeThink URL when discussing “track record.”
